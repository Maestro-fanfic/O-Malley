O'Make Way for Jack Slash

scrapped by this author, open to someone braver

Open for adoption

The Silence of the Lambs x Worm

Clarice Starling and/or Hannibal Lecter, dropped into Jack Slash of the Slaughterhouse Nine.

Why it's here: I never started this one. It was shelved alongside Bonesaw before any outline work began: both are Slaughterhouse Nine-tied entries, and the Nine turned out to be off the table for me entirely, I wasn't strong enough to write what was essentially a slasher film. If the Hannibal Lecter/Clarice Starling passenger concept appeals to someone else with a different, non-Nine driver in mind, that's a related but genuinely new entry, not a repair of this one.

This one's up for grabs: identified, but not something this author expects to ever complete. Per Rule 9a, anyone's welcome to run with it under the series' standard credit and disclaimer terms. Say a word first if you're claiming it, so it doesn't get built twice.
